02 / Email Breach Intel

Mengecek apakah email tercatat pada insiden kebocoran di Have I Been Pwned. Memerlukan API key HIBP di backend.

Email tidak disimpan oleh halaman ini. Permintaan dikirim ke backend HIBP.

03 / Password Exposure Check

Pemeriksaan memakai model k-anonymity Pwned Passwords. Hanya 5 karakter awal hash SHA-1 yang dikirim; password asli tidak dikirim.

Password diproses lokal di browser; hanya potongan hash yang dikirim.

Jangan gunakan password utama jika tidak nyaman mengujinya. Hasil “tidak ditemukan” bukan jaminan password aman.

04 / SHA-256 Hash Generator

Menghasilkan hash SHA-256 secara lokal di browser. Ini fungsi kriptografi, bukan enkripsi.

Hash akan muncul di sini.
